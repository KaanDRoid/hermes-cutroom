# Contributing

Read [the documentation index](docs/README.md) first, especially [status](docs/status.md), [development](docs/development.md) and [collaboration](docs/collaboration.md).

Use focused branches and pull requests. Keep code and documentation English. Include a reproducible test command and exact results; distinguish skips, mocked adapter contracts, real media/model acceptance and native UI/live-service acceptance.

Do not commit user recordings, model binaries, environments, credentials or generated media. Coordinate file ownership before parallel work, and never publish or upload creator content without explicit consent.
